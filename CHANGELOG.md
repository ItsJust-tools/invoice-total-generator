# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-25

### Added

- Line-item invoices with description, quantity and unit price
- Global tax rate with per-line tax toggle
- Percentage or flat discount with zero clamping
- Live subtotal, discount, tax and grand total with currency selection
- Editable header with auto-incrementing invoice number and date picker
- Copy as Markdown table and as plain-text summary
- Print view and shareable URL state
